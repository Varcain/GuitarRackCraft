# FEX-Emu patches for the FEX pivot

Patches we write against upstream FEX-Emu (github.com/FEX-Emu/FEX, pinned
to a specific commit) to make it cross-compile and run on Android Bionic
arm64 would go here as `NNNN-name.patch`. None are needed at the moment:
`scripts/build-fex-pe.sh` builds the pinned commit as is.

We may *read* third-party diffs for reference, but we do not vendor
patches verbatim.
